# =============================================================================
# Notes
# =============================================================================
#
# - `pytest-benchmark` is used by `tests/test_aee.py::TestTiming` for
#   optional microbenchmarks; the test suite runs without it (the
#   timing tests are marked `slow` and use `time.perf_counter` directly
#   rather than `pytest-benchmark`).
#
# - `black` and `ruff` are pinned to versions that agree on line
#   length (100) and that both respect the pyproject-less configuration
#   (the artifact has no pyproject.toml; both tools read their config
#   from setup.cfg if present, or use defaults). The defaults are what
#   the current source tree is formatted to.
#
# - `mypy` is run against `src/` and `scripts/` but not against
#   `tests/` (test files are more permissive; the type annotations in
#   the test files are illustrative, not strict).
#
# - A fresh checkout of the artifact must pass `pytest tests/ -v`
#   without any of the *slow* tests; see tests/conftest.py for the
#   --run-slow flag.
